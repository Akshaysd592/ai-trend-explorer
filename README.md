# 🚀 AI Trend Analyzer

A production-grade **Java Full Stack Microservices** project built to demonstrate strong backend engineering, scalable system design, modern React/Next.js development, event-driven architecture, and cloud-native deployment.

---

# 📌 Project Vision

Build an **AI Trend Analyzer** that aggregates trending AI projects from **GitHub**, **Hugging Face**, and **Product Hunt**, analyzes them using AI, and presents the results through a modern web application.

This project is designed to demonstrate:

- Java 21 & Spring Boot mastery
- Hexagonal Architecture
- Microservices
- Spring Security & JWT
- PostgreSQL & Liquibase
- Redis
- Kafka
- gRPC
- AOP & Logging
- React + Next.js + TypeScript
- Redux Toolkit
- TanStack Query
- Docker & Kubernetes
- GCP deployment
- CI/CD
- Testing
- Observability

---

# 🛠️ Technology Stack

## Backend

| Area | Technology |
|------|------------|
| Language | Java 21+ |
| Framework | Spring Boot |
| Build Tool | Gradle |
| Architecture | Hexagonal Architecture |
| API | REST |
| Internal Communication | gRPC |
| Database | PostgreSQL |
| ORM | Spring Data JPA + Hibernate |
| Database Migration | Liquibase |
| Security | Spring Security + JWT |
| Caching | Redis |
| Messaging | Apache Kafka |
| External APIs | Spring WebClient |
| Resilience | Resilience4j |
| Cross-cutting Concerns | Spring AOP |
| Monitoring | Spring Actuator |

## Frontend

| Area | Technology |
|------|------------|
| Framework | Next.js |
| UI | React |
| Language | TypeScript |
| State Management | Redux Toolkit |
| Server State | TanStack Query |
| Styling | Tailwind CSS |
